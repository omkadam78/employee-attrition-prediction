# Dataset

The project uses the IBM HR Analytics Employee Attrition and Performance sample dataset with 1,470 rows and 35 columns. The included file was retrieved from IBM's public `employee-attrition-aif360` GitHub repository:

`https://github.com/IBM/employee-attrition-aif360/blob/master/data/emp_attrition.csv`

The data is a fictional teaching sample. It does not represent a real employer and cannot establish causal relationships.
